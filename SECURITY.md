# Security Policy

## Supported versions

SENTINEL has not published a stable, versioned release. While the project is
actively maintained, security fixes are made to the `main` branch on a
best-effort basis. There is no security-support guarantee for forks or
unreleased commits.

## Reporting a vulnerability

Please do not report suspected vulnerabilities in a public issue or discussion.

1. If GitHub private vulnerability reporting is enabled for this repository,
   use **Security → Advisories → Report a vulnerability**.
2. If private reporting is unavailable, contact the project owner privately
   through the GitHub profile at <https://github.com/livejpsingh> and request a
   secure disclosure channel before sending sensitive details.
3. Include the affected commit or version, impact, and a concise reproduction
   description. Do not include real credentials, tokens, or personal data.

The maintainer will review reports and coordinate any fix and disclosure
details. This project does not currently promise a response or remediation SLA.
